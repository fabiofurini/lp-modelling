# Interactive lab

The models of the course solved to optimality in the browser: change the data with the sliders or by
dragging the points, and a simplex method written in JavaScript recomputes the solution, with the same
numbers as the Python scripts and the lecture notes. Pick an app: it opens full page.

## Models side by side

<div class="grid cards" markdown>

-   :material-truck-delivery-outline: **Transportation from warehouses to customers**

    ---

    The app solves a linear programming model to optimality in the browser: the data, the symbolic model, the numerical model of the instance and the optimal solution with its graph.

    [Open the app →](transportation.md)

</div>
